# 评分标尺

每个维度 1-5 分。

## 创作维度

- **因果逻辑**：升级来自先前的选择。
- **人物主体性**：行动源于欲望，不是编剧方便。
- **喜剧清晰度**：观众能看懂被违反的规则。
- **升级质量**：赌注、意义或地位改变，不只是变吵。
- **原创性**：前提、人物、世界、语言、回收都独立表达。
- **机制节制**：2-3 个机制协同，不堆砌。
- **视觉/可拍性**：动作能表演、能拍摄。
- **情感回收**：结尾赢得真实的人性后果。
- **媒介适配**：节奏与密度匹配目标平台。
- **网络传播性**：至少有一个记忆点（可截图/可复述/可模仿/可争论）。
- **锋利度**：至少一处不舒服的真实，不是全安全笑点。

## 研究维度

- **来源权威**：证据与主张匹配。
- **事实精确**：姓名、日期、角色、数字、辖区准确。
- **事实/解读分离**：分析不冒充创作意图。
- **时效性**：易变事实带核验日期。
- **引用完整**：重要主张可追溯。

## 硬失败规则

- 身份冒充或虚假背书。
- 未经授权的脸/声音克隆。
- 大量复制受保护文本，或提供可识别场景的替代品。
- 伪造来源、引语、奖项、采访、指标或法律要求。
- 破坏前提或结局的逻辑矛盾。

## 发布规则

无硬失败 + 所有关键维度 ≥ 3 + 相关维度均分 ≥ 4 才交付。先修最低分维度。
