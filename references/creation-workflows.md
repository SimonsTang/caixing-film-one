# 创作工作流（按媒介）

## 短视频 15-90 秒

1. 一句话表达前提。
2. 前 10% 用未解决的视觉矛盾做钩子。
3. 建立一条规则 + 一个人物欲望。
4. 升级两次，第二次重新解释第一次。
5. 回收前面出现的道具、动作或台词。
6. 以后果或情感反冲收尾，不解释。

交付：带时间码的节拍表、对白、镜头/表演提示、字幕与封面文案选项。不承诺播放量数据。

## 短场景 / Sketch 2-8 分钟

1. 画出地位图与私人目标。
2. 选一个规则冲突 + 一个辅助机制。
3. 用七步架构写节拍。
4. 中点必须改变谁控制这场戏。
5. 结尾既解决外部事件，又改变一段关系。

## 广告 15-30 秒

1. 保留产品真实信息与必须宣称。
2. 让产品在因果链上必要，不在笑话后贴标签。
3. 不虚构功效、代言、评价、比较宣称。
4. 给三条完全不同路线：人物驱动 / 情境驱动 / 道具驱动。
5. 附白话宣称核对与 AI 披露提示。

## 长片 / 系列开发

1. 把主题定义为冲突，不是口号。
2. 建立有独立规则的原创世界。
3. 主角、对手、盟友有互不兼容但都可理解的目标。
4. 按段落追踪铺垫-回收、地位变化、情感债。
5. 写对白前，审计每个大节拍与既有作品的相似度。

## 改写与诊断

先诊断再改写：

```text
症状 → 结构原因 → 最小修改 → 可选大胆重构
```

保留用户认定的核心。用机制和人物逻辑解释改动，不要说"某创作者会怎么做"。

## 三概念差异测试

三个概念只有满足以下至少三项才算实质不同：

- 主角职业或社会位置；
- 场景与支配规则；
- 主机制；
- 承载回收的道具或动作；
- 关系赌注；
- 情感结局。
